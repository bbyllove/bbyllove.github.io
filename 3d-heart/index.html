⚠️ 页面脚本未能运行

本页的 3D 内容与设置面板依赖 main.js（ES Module）。当它没有正确加载/执行时，所有控制项（钻石滑杆、预设按钮、文字、颜色等）都无法操作 —— 看起来就像功能「坏了」。

请改用本地 HTTP 服务打开（不要直接双击 index.html）：

cd 3d-heart
python3 -m http.server 8000

然后在浏览器访问 http://localhost:8000/；若仍异常，请强制刷新（Cmd/Ctrl+Shift+R）以丢弃旧的脚本缓存。详见 README.md。

台词显示在画面中间偏上的空白区，一行一句、空行忽略；字体 / 字号与主场景文字共用同一份字体表。四种切换效果：淡入淡出（原地淡入 → 停留 → 原地淡出）、上浮交替（当前句慢慢上移淡出，下一句同时从下方浮现并升回原位）、烟消云散（当前句逐字飘散成烟，下一句在原地逐字凝聚）、翻页打字机（当前句像书页一样绕左边翻走，下一句在原地逐字打出、带一支跟着字走的光标；句子越长打得越久，超长句整块淡入）；「间隔」是每句的停留秒数，过场时长随它自动伸缩。设置随全局配置保存，刷新自动恢复。

相册管理

玩法：← / → 切换照片（圆环 = 转环切换、扇形 = 换手牌），空格 = 下一张，点缩略图跳转；点当前照片进入聚焦（灯箱） —— 聚焦后滚轮 / 双指 0.5×–4× 缩放（放大可超出画幅裁切看细节），点照片或 ESC 退出聚焦；ESC 或右上「退出」离开陈列室。聚焦时图注与本侧栏一起隐藏，画面只留照片和它自己的那句台词；画面底部不再放操作提示条，说明都收在这里。

进入时自动装载内置相册（张数由 assets/gallery/manifest.json 决定）；自己添加的图片排在后面，保存在浏览器本地（IndexedDB）。
